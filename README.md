# Platformer Game 🎮

A fun, mobile-friendly platformer game built with HTML5 Canvas! Jump, collect coins, and reach the goal flag to advance through levels.

## Features

- **Mobile-friendly**: Touch controls for smartphones and tablets
- **Keyboard controls**: Arrow keys or WASD for desktop
- **Multiple levels**: Progress through increasingly challenging stages
- **Collectibles**: Gather coins for points
- **Smooth animations**: Fluid player movement and visual effects
- **Responsive design**: Works on phones and desktops

## How to Play

### Desktop Controls
- **Arrow Keys** or **WASD** to move left/right
- **Space**, **W**, or **Up Arrow** to jump

### Mobile Controls
- Use the on-screen buttons to move and jump

### Objective
- Collect golden coins for points (+10 each)
- Reach the green flag to complete the level (+50 bonus)
- Don't fall off the platforms!

## Development

Built with pure HTML, CSS, and JavaScript - no frameworks required!

### To run locally:
1. Clone the repository
2. Open `index.html` in your browser
3. Start playing!

## Tech Stack

- HTML5 Canvas for rendering
- Vanilla JavaScript for game logic
- CSS3 for styling and responsive design
- GitHub Pages for hosting
